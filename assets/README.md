# Assets 資料夾

把以下檔案放在這裡 (一次性):

| 檔案 | 用途 | 規格 |
|------|------|------|
| `logo.png` | 頻道 Logo | 1024x1024 PNG |
| `cover.jpg` | Podcast 封面 (Apple/Spotify 需要) | 3000x3000 JPG, < 500KB |
| `intro.mp3` | (選用) 片頭音樂 5-10 秒 | 192kbps mp3 |
| `outro.mp3` | (選用) 片尾音樂 | 192kbps mp3 |
| `fallback.png` | DALL-E 失敗時的備用插畫 | 1792x1024 PNG |

> 設計工具推薦:Canva (https://canva.com) — 有免費的 Podcast 封面模板,3 分鐘搞定。
